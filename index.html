A course that only teaches "type this syntax" is already behind — AI writes syntax faster than any human. A course that only teaches "prompt an AI" produces people who can't tell when the AI is wrong. This course is built as neither alone: you learn Python the traditional way first — by writing it yourself, understanding why it works, getting it wrong and fixing it — and only then does each chapter ask you to direct an AI at the same problem, and to review its answer like you don't trust it yet. That order matters. Judgment about AI-generated code has to come from somewhere, and it comes from having done the work without AI first.

How to use this course

  • Read the lesson, take the quiz, do the exercises, then build the project — in that order.
  • Every quiz question has its own Check button, so you get instant feedback without submitting anything or waiting for a grader.
  • "Go Deeper" boxes are optional — skip them on your first pass if you just want the essentials, come back later if you want the full picture.
  • Running the Python code requires Python 3 installed on your computer — everything else (lessons, quizzes) works right in this browser.
  • On chapters with the GenAI prompt box (Chapter 25 onward): after you understand a worked example on your own, write the prompt you'd give an AI assistant to build it, then reveal a strong reference prompt to compare against — try your own in Claude, ChatGPT, or whatever you use, and see how close you got. On the project's "AI-paired" page, do the reverse: read an AI-generated solution skeptically and try to find its planted bugs before revealing them.
